# 입력과 해석

각 함수는 메모리의 DataFrame 또는 HTML 문자열을 받습니다. 파일 수집·로그인·데이터 다운로드를 수행하지 않습니다. 아래 열 이름은 원본 분석 코드와의 연결을 위해 보존했습니다.

- `food_sales(orders, tip)`: `음식금액`, `가게즉시할인`, `고객결제금액`, `서비스유형`. 음식금액이 있으면 즉시할인을 차감하고, 없으면 고객 결제액에서 가게배달의 전달된 배달료 가정을 차감합니다. 정산 순이익을 계산하는 함수는 아닙니다.
- `glm(formula, data, family)`: statsmodels 수식과 DataFrame. `poisson` 또는 `nb`를 사용합니다. `nb`는 분산 파라미터를 추정하고 실패하면 1.0을 사용합니다. 결과는 관측 연관성으로 해석해야 합니다.
- `baskets_app(items)`: `채널`, `주문번호`, `메뉴_표준`, `메뉴분류`, `수량`, `옵션`, `수령`, `월`, `시각`, `음식금액`. 주문별 금액은 각 품목 행에 같은 값으로 제공해야 합니다. `옵션`은 `+`로 구분하고, 빈 값은 옵션 없음으로 처리합니다. 취소·반품은 이 함수 호출 전에 정리해야 합니다.
- `baskets_receipt(lines)`: datetime형 `영업일자`, `전표번호`, `구분`, `상품명`, `수량`, `금액`, `채널`. 원본 정의대로 주류를 제외한 품목 금액을 음식금액으로 집계합니다.
- `pairs(baskets, channel, min_cnt)`: `구분`, `items` 열. 같은 주문에 같은 품목이 여러 번 있어도 지지도에서는 한 번만 셉니다. `basket_patterns`와 `two_main_combos`에는 주 메뉴 목록을 별도로 전달합니다.
- `WalkField(road_points, max_access_m)`: `x`, `y`, `net_m`. 좌표와 거리는 같은 미터 단위의 투영 좌표계여야 합니다. `net_m`은 각 도로 점부터 목적지까지 미리 계산한 네트워크 거리입니다. 호출 시 가까운 도로 점 최대 `k`개 중 접근 거리와 네트워크 거리 합의 최솟값을 반환합니다. 접근 한도 내 도로 점이 없으면 무한대이며, 전체 경로 탐색을 수행하는 함수는 아닙니다.
- `parse_naver(html)`, `parse_generic(html)`: HTML 문자열에서 제목·작성자·본문·이미지 참조 등을 읽습니다. 익명화 함수가 아니므로 실제 HTML에서 생성한 결과를 그대로 공개하지 마세요. 예제에는 직접 만든 가상 HTML만 사용합니다.
